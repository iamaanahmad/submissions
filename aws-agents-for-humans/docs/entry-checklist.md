# AWS Agents for Humans entry checklist

Status: prototype review package, not registered or submitted by this build.

## Proposed entry copy

Name: Handoff Guard.

Track: Professional Agents.

Pitch: A local agent that catches incomplete delivery evidence before a small studio hands work to a client.

Problem: Project managers must reconcile missing files, changed evidence, failed checks, and pending approvals across a handoff.

Solution: Strands coordinates two bounded tools to inspect evidence and create a checked review packet.
A local model suggests next actions. Deterministic code owns the verdict and copies only verified items.

Impact: The prototype makes unresolved handoff items visible before a delivery claim is sent.
Time savings and customer adoption have not been measured.

Technology: Python, Strands Agents SDK, Pydantic, llama.cpp, and Qwen3 1.7B.
No AgentCore deployment or paid AWS inference is claimed.

Disclosure: This original prototype was built with an AI coding assistant on September 7, 2026.
The synthetic scenarios are demonstrations, not customer case studies.
The public libraries and model remain their authors' work.
