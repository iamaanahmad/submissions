# Mermail Policy Change Radar

Policy Change Radar reviews vendor policy-update emails in a Mermail inbox. It compares evidence-backed old and new claims, ranks effective dates, and drafts review questions.

- [Upstream skill pull request](https://github.com/Nudgen-Marketing/mermail-skills/pull/149)
- [Demo video and release](https://github.com/iamaanahmad/submissions/releases/tag/mermail-policy-change-radar-v1.0.0)
- AI client: OpenAI Codex CLI
- Demo data: four labeled synthetic vendor notices
- Safety: the workflow does not send email or accept terms

The demo covers the prompt, Mermail connection, live inbox searches, source email reads, agent completion, and the final ranked result.
